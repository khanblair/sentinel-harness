Built with mdBook. It is written in Rust, gives a left menu, search, and light and dark themes. The theme uses the same colors and fonts as the app.
Source in the repo. A site/ folder with one markdown file per page. A GitHub Actions workflow builds and publishes it.
Same writing rules. Plain words, short sentences, and the slop check runs on the site text too.

Home page. Grey boxes are placeholders for text and images.
