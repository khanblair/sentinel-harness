# The stream

## What it is

The stream is the ordered feed of one run, and the composer sends your instructions into it.

## Steps

1. Read the stream from top to bottom. It shows the plan, the waves, agent steps, file checkpoints, barriers, verdicts, approvals, and the report, in that order.
2. Type a plain instruction in the composer to send it to Sentinel. Sentinel routes it by difficulty.
3. Type a slash command to run a control. The commands are `/pause`, `/resume`, `/stop`, `/cap`, `/agent`, `/focus`, `/kill`, `/plan`, `/brain`, `/report`, and `/help`.
4. Open the send-to chip to send a message to one agent instead of Sentinel.
5. Press Ctrl+K on Windows or Linux, or Cmd+K on macOS, to open the command palette for agents, panels, and settings.
