# Add files, folders, a backlog, or a note

## What it is

The plus button in the composer attaches files, folders, a backlog, or a note to your next message. Attachments give the planner and the agents context. They never reserve files.

## Steps

1. Click the plus button beside the composer. The menu has four entries:
   - **Add files** chooses files from the repository, or uploads a file from this device. On a phone it also offers the camera roll.
   - **Add a folder** chooses a folder of the repository. It is a hint about where the work belongs.
   - **Use a backlog file** chooses a file in the repository, or uploads one. Each section of the file becomes a task.
   - **Add a context note** adds text that goes into the agents' prompts.
2. Check the chip. Each choice becomes a chip above the text box, with an icon, a short name, and an x. Click the x to remove a chip.
3. Send your message. The chips go with it, and they show on that message in the stream.
4. On desktop, drop files on the stream, or paste a file into the text box. Each file becomes a chip.
5. Check the limits. Each upload can be at most 1 MB. Every file reaches the planner and the agents as a path. A small file's text goes in too. A big file goes as a path only. A chip that cannot be used says why in its tooltip: a file over 1 MB, or a path outside the repository.
6. Uploads are saved under `.sentinel/chats/<chat>/attachments/`. They never land in the tracked tree.

## Tip

Attached files are hints. They never reserve files. Reserved files are still the only write rule.
