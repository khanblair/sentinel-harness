# Start a chat

## What it is

A chat opens in one project. Send a message in it, and Sentinel starts a run to do the work.

## Steps

1. Open a new chat in one of three ways. Click New chat at the top of the sidebar. Click the plus on a project header. Press Ctrl + Shift + O on Windows or Linux, or Cmd + Shift + O on macOS. The command palette also opens a new chat.
2. Type what you want built in the composer. Say what done means. Press Enter to send, or Shift + Enter for a new line.
3. Sentinel's planner turns the message into one or more tasks, and a run starts. Watch the plan and the work in the stream.
4. Check the title. An empty chat has no title until you send a message. Then the title becomes the first line of that message, cut at 48 characters. If you attach a backlog file, the title becomes the file name.
5. Rename the chat at any time. See [Rename, pin, archive, and delete](manage-chats.md).

## Tip

A message in an idle chat starts a run. A message sent while that chat's run is live goes to the agents as a note. See [One run at a time](one-run-at-a-time.md).
