# Chats

## What it is

A chat is one conversation with Sentinel in a project. You open a chat, say what you want built, and Sentinel plans it, runs the agents, and checks the result. A chat holds many runs, one after another.

## Steps

1. Read [Start a chat](start-a-chat.md) to open a chat and send the first message.
2. Read [Add files, folders, a backlog, or a note](attachments.md) to add context with the plus button.
3. Read [Rename, pin, archive, and delete](manage-chats.md) to keep the chat list in order.
4. Read [One run at a time](one-run-at-a-time.md) to learn why a project has one live run.

## Tip

A project is a repository folder. A chat is a conversation in a project. A run is one pass of the harness that a message starts.
