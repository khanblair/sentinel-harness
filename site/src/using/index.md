# Using Sentinel

## What it is

The using pages explain chats and each part of the run screen: the stream, reserved files, permissions, agents, panels, and the budget.

## Steps

1. Read [Chats](chats/index.md) first to open, name, and keep your conversations with Sentinel.
2. Read [The stream](stream.md) to see what a run shows. Every other part supports it.
3. Read [Reserved files and waves](reserved-files.md) to see how tasks avoid collisions.
4. Read [Permissions and approvals](permissions.md) to set how much agents may do alone.
5. Read [Agents](agents.md) to see, focus, and steer each agent.
6. Read [Panels](panels.md) to find each panel from the top bar or the More menu.
7. Read [Budget](budget.md) to learn when Sentinel stops new work.

## Tip

Open the stream first. The other panels sit beside it.
