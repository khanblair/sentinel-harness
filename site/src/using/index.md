# Using Sentinel

## What it is

The using pages explain each part of the run screen: the stream, reserved files, permissions, agents, panels, and the budget.

## Steps

1. Read [The stream](stream.md) first. Every other part supports it.
2. Read [Reserved files and waves](reserved-files.md) to see how tasks avoid collisions.
3. Read [Permissions and approvals](permissions.md) to set how much agents may do alone.
4. Read [Agents](agents.md) to see, focus, and steer each agent.
5. Read [Panels](panels.md) to find each panel from the top bar or the More menu.
6. Read [Budget](budget.md) to learn when Sentinel stops new work.
