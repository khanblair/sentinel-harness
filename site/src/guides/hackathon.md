# Hackathon mode

## What it is

Hackathon mode and the run checklist keep a live demo honest and within the announced budget.

## Steps

1. Run the project checks, and confirm they pass.
2. Confirm Tailscale is up on the PC and on the phone, and that the phone is paired.
3. Set the cap at or below the announced cap.
4. Confirm the detected tools show at least 3 agents across 2 tools or models.
5. Set the Brain mode to read-only. Turn Telegram off, or set it to Status only.
6. Empty the logs folder, or move its contents to an archive.
7. Start the run with one command. Do not change code during the run.
