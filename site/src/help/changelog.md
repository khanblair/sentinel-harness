# Changelog

## What it is

The changelog will list each released version. Until a release is published, the progress tracker shows the work by phase.

## Steps

1. Open the [progress tracker](https://github.com/khanblair/sentinel-harness/blob/main/docs/progress-tracker.md) on GitHub to see the status of each phase.
2. Check the release page on GitHub for published versions.
3. Expect each version to be tagged as `vX.Y.Z` after the checks pass. Versions follow semver.

## Tip

Versions follow semver, set once in the root `Cargo.toml`.
