# Help

## What it is

Help covers common problems, the questions people ask most, and the release history.

## Steps

1. Find your symptom in [Troubleshooting](troubleshooting.md).
2. Check [FAQ](faq.md) for a question about how Sentinel works.
3. Open [Changelog](changelog.md) to see what changed in each release.
