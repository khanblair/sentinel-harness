# Brain

## What it is

The Brain is a folder of plain markdown notes. Agents read it as memory, every run can write to it, and you browse and edit it in the Brain panel.

## Steps

1. Read [Notes and links](notes.md) to learn the note format and the Brain panel.
2. Read [Agent memory and the run journal](memory.md) to see which notes an agent receives.
3. Read [Lessons](lessons.md) to learn how a lesson is proven before it is trusted.
4. Read [Brain care](care.md) to schedule upkeep and review proposals.
5. Read [Using the vault in Obsidian](obsidian.md) to edit the same folder in Obsidian.
