# Reference

## What it is

The reference pages list each settings section, the appearance options, the shortcuts and commands, and the status words.

## Steps

1. Read [Settings](settings.md) to find a setting by its section.
2. Read [Appearance](appearance.md) to set the theme, colors, and type on this device.
3. Read [Shortcuts and commands](shortcuts.md) to run controls from the keyboard or the composer.
4. Read [Status words](status-words.md) to learn what each label and shape means.

## Tip

Use the command palette to jump to a setting when you do not remember its section.
