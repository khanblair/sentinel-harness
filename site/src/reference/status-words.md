# Status words

## What it is

Status words name the state of a task, a lesson, or a note. Each one has a label and a shape, as well as a color.

## Steps

1. Read the label first. Every status has a label, so color is never the only signal.
2. Use this table for task statuses:

| Status | Shape | Label |
|---|---|---|
| Ready, Planned | Hollow circle | Ready |
| Waiting | Square | Waiting |
| Running | Triangle | Running |
| Verifying | Diamond | Verifying |
| VERIFIED | Filled circle | Verified |
| BLOCKED | Octagon | Blocked |
| CONTRADICTION | Split circle | Contradiction |
| SKIPPED | Dash | Skipped |
| PARTIAL | Half circle | Partial |

3. Use this table for lessons and notes. Rings are used so they never look like task statuses.

| State | Shape | Label |
|---|---|---|
| Candidate | Dotted ring | Candidate |
| Proven | Ring with a check | Proven |
| Rejected | Ring with a bar | Rejected |
| Retired | Dashed ring | Retired |
| Quality note | Hexagon | Note |
