# Welcome

## What it is

Sentinel is a coding tool you talk to. You open a chat in a project and say what you want built. Sentinel runs several coding agents on one repository, keeps them out of each other's files, and shows the whole run in one stream.

## Steps

1. Plan. Sentinel predicts which files each task will write.
2. Reserve files. Each file has one writer at a time.
3. Agents work. Tasks with no shared files run together in a wave.
4. Tests decide. The full suite runs at each barrier. Only the verifier marks a task VERIFIED.
