# Try it

## What it is

Try it runs the interactive prototype of Sentinel in your browser. The prototype uses simulated data.

## Steps

1. Wait for the prototype to load below.
2. Use the toolbar above the app to switch between the desktop, tablet, and phone previews.
3. Set the demo speed, open the guide or the tour, or reopen the install and setup screens.
4. Press Reset to clear the prototype's saved settings.
